# Gemini prompt: Agentic performance orbit

Use this prompt to create a visual companion for the guide **Skills in the agentic performance system**. It is designed for a presentation audience that is early in its agentic-AI journey.

## Static key visual prompt

Create a refined, presentation-ready editorial illustration in 16:9 landscape format (3840 × 2160), with no text, logos, UI chrome, or watermarks.

Concept: **Skills are the reusable playbooks that help turn an AI model into a dependable professional system.** Show a calm “agentic performance orbit”: a luminous central core representing the AI agent, surrounded by seven clearly distinct, evenly spaced orbital nodes. The nodes should be visually symbolic rather than labeled:

1. a faceted prism or constellation for Model
2. a small field guide / braided instruction card for Skills
3. a clean, structured library / data lattice for Context & data
4. a precise articulated tool or connector for Tools & software
5. a subtle routing pathway / orchestration pattern for Harness & architecture
6. a calibration dial, test grid, or verification mark for Evals & observability
7. a translucent boundary ring with a quiet shield for Governance & trust

Composition: make the Skills node the most luminous and closest to the central core. The other six nodes form a single elegant ring, each connected by thin, purposeful lines. Use generous negative space, avoid a crowded “tech diagram,” and make the overall image feel optimistic, calm, and human-centered. The visual should communicate that professional outcomes emerge from a system of mutually reinforcing choices—not from the model alone.

Design language: editorial information design meets premium science-museum exhibit; polished but not corporate clip art. Dark midnight-indigo background, electric teal and soft periwinkle light, warm amber accent only for Skills, frosted-glass material details, delicate depth and shadow. High contrast, crisp at slide scale. No gradients that muddy the structure. No tiny details or illegible pseudo-text.

Reserve the upper-left 35% of the canvas as calm, dark negative space for slide headline text to be added later. Keep the lower-right system visual strong but balanced.

## Motion prompt: 12-second looping presentation animation

Create a seamless 12-second 16:9 landscape looping animation from the same visual system. No text, logos, UI chrome, watermarks, spoken audio, or sound effects.

The camera faces a calm, dimensional “agentic performance orbit”: a central luminous AI-agent core with seven orbiting symbolic nodes—model prism, Skills instruction card, context/data lattice, tools connector, architecture routing pathway, eval calibration grid, and governance boundary ring.

Motion choreography:

1. 0–2 seconds: all seven nodes appear as a coherent, quiet orbit around the central core; fine connective lines softly pulse.
2. 2–10 seconds: the orbital ring rotates slowly clockwise. As each node reaches the top-center “focus position,” it gently enlarges, brightens, and comes into sharp focus for about one second; the rest remain visible but quieter. The focus order is Model → Skills → Context & data → Tools & software → Harness & architecture → Evals & observability → Governance & trust.
3. When Skills reaches focus, give it a subtle warm-amber glow and let the links between the core and the other nodes become briefly clearer, showing Skills as a reusable bridge between model capability and reliable work.
4. 10–12 seconds: the orbit returns exactly to its opening position and lighting so the loop is imperceptible.

The motion must be slow, intentional, and easy for a new audience to follow—one idea in focus at a time. Maintain stable node identity and spacing; no node collisions, morphing symbols, rapid camera moves, or flashy particle effects. Use dark midnight-indigo space, electric teal/periwinkle system light, and warm amber only on the Skills moment. Premium editorial motion design, gentle parallax, high contrast, generous negative space in the upper-left for a presenter’s title.

## Optional slide title and talk track

Suggested title: **Professional agentic outcomes are a system property.**

Suggested 20-second talk track: “The model matters, but it is only one part of the outcome. Skills are reusable playbooks: they guide how the model applies tools, context, and software to a specific kind of work. The orbit helps us see each lever in turn—and why evaluation and governance make the whole system dependable.”
